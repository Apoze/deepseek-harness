# Agent Note: 原生生成准入与有界恢复

Status: implemented

[English](2026-09-09-native-generation-admission.md) | 中文

## Problem

输出限制可能截断原生工具调用。将该生成视为最终响应会让不完整语法污染重放，并阻止框架完成本可恢复的任务。在新输入之前测量压力，也无法准确判断最终请求是否可发送。

## Decision

LLM 接口允许检查与实际发送相同的请求投影。代理循环记录检查结果并等待最终准入。达到上限或结构无效的生成先保存为持久化尝试，再进入恢复瀑布；只有被接受的响应才会执行工具。策略负责重试预算和记录技术上下文。原生 NInfer 适配器负责协议准备与服务器计数；显示文本的解析器不会执行命令。

现有压缩器负责保持工具关系完整的上下文缩减，并在替换前拒绝不可用摘要。辅助调用拥有独立的推理、工具和输出设置以及持久化请求记录。计量区分当前输入与尝试累计用量。进程重启后，命名 SDK 会话通过现有注册表恢复，并检查工作目录身份。

重试在精确计数前从现有提示词组装结果恢复被压缩移除的运行时上下文，不重新接纳用户输入。仅含标点的摘要在替换历史之前失败。压缩始终遵守近期历史保留要求，即使这意味着没有可缩减的范围。

## Alternatives considered

轮次完成后重试，已经无法保留一致的结果。网络重试会重复相同的超大生成。拼接前缀可能构造出未经模型完整生成的可执行参数。新增事务式写入工具会重复现有工具，也不能解决请求容量问题。

## Consequences

被拒绝的尝试不会执行部分被接受的工具批次。可选的提供方能力让其他适配器继续使用原有路径。精确计数不能预测输出长度，也不能保证语义正确。有界恢复仍可能以未完成状态结束。必需事件要求使用本版本读取器；部署保留原始会话版本以便回滚。验证覆盖真实工具效果、协议限制、取消、已加载上下文的摘要和进程重启，以及 SDK 和会话重放快照。
