# Agent Note: 0.2.1-alpha.4 上的 NInfer 原生支持

Status: implemented

[English](2026-09-28-ninfer-native-020.md) | 中文

## 问题

旧版原生分支使用 V4 之前的消息、设置和预设接口。直接升级依赖会丢失精确请求准入和不完整输出的安全处理。

## 决策

保留上游 0.2.1-alpha.4 的消息投影，添加可选的预备检查。原生恢复先于工具执行，普通提供方保持上游行为。持久化 SDK 会话使用上游显式恢复 API。旧格式读取器仅提升字段完全匹配的第二版一次性子代理描述符；它与第三版的身份语义相同。

## 考虑过的替代方案

完全重用旧循环会丢失 V4 工具更新投影。改写所有旧描述符则会接受不受支持的可继续会话。两种方案均被否决。

## 后果

NInfer 和恢复插件依赖此分支。普通提供方不需要检查。33 个结构不受支持的历史会话保留在活动主目录之外。回滚需同时恢复旧运行时及其匹配的主目录。

## 验证

核心构建；LLM、代理循环、压缩、SDK 和迁移测试；六个恢复 SDK 场景；真实 NInfer 文本及文件系统调用；OpenDesign 标准输入输出；Web 插件、搜索、抓取和下载检查。保留的历史转换无失败。
